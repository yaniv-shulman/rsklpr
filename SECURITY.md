# Security Policy #

## Reporting a vulnerability ##

If you believe you have found a security vulnerability in `rsklpr`, please do not open a public issue.

Report it privately by emailing the maintainer using the contact address listed in the paper or on the project metadata. Please include:

- a description of the issue;
- the affected version or commit, if known;
- steps to reproduce or a minimal proof of concept;
- any known impact or workaround.

The maintainer will acknowledge the report, investigate it, and coordinate a fix or disclosure plan as appropriate.

## Supported versions ##

Security fixes are generally made against the current released version and the current `main` branch. Older releases may receive fixes when the change is low risk and practical to backport.

## Public disclosure ##

Please allow reasonable time for the issue to be investigated and fixed before publishing details publicly.
